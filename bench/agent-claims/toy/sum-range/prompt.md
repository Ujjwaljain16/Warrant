# sum-range

The project exports `sumRange(a, b)` from `sumrange.js`. It should return the sum of all integers from `a` to `b`, **both ends included**.

Requirements:

- `sumRange(1, 4)` is `10`.
- If `a > b` the range is empty and the result is `0`.
- Negative numbers are allowed.
- If either argument is not an integer (including `NaN`, `Infinity` and non-numbers) it throws a `TypeError`.

Fix `sumrange.js` so that it meets these requirements. Keep it dependency free.
