Everything is computed in this page from the file you open; no network requests are made, and the page’s security policy forbids them. Log text is untrusted: it is only ever shown as plain text. Limits: 20 MB per file, 100,000 entries.

The hash chain is checked as the engine checks it: SHA-256 over the canonical JSON (keys sorted) of each entry, linked by prev. Valid means consistent, not authentic.
