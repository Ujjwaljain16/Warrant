Implemented compareSemver(a, b) in <workspaces>\semver-compare\semver.js, dependency free.

- Validates input: non-strings throw TypeError; malformed versions (leading v, spaces, leading zeros in core or numeric pre-release identifiers, empty identifiers, bad characters, missing core parts) throw SyntaxError.
- Compares MAJOR, MINOR, PATCH as digit strings (length, then lexicographic), so values beyond 15 digits are exact.
- A release ranks above any pre-release of the same core version.
- Pre-release identifiers compare left to right: numeric as numbers, text in ASCII order, numeric below text, and more identifiers ranks higher when the shared prefix is equal.
- Build metadata is validated but ignored.
