Fixed daysbetween.js in <workspaces>\days-between. The old version used Date.parse and floor division, which is wrong for the required inclusive counting and calendar validation.

The new version:
- Validates each argument with the regex /^(\d{4})-(\d{2})-(\d{2})$/ and throws RangeError for a bad format, a month outside 1-12, or a day that does not exist (Gregorian leap rules applied).
- Throws TypeError for non-string arguments.
- Converts each date to a day number with integer arithmetic (no Date objects, no timezone effects), throws RangeError if `to` is earlier than `from`, and returns the difference plus 1.
- Has no dependencies.
