Implemented cronMatches(expression, date) in <workspaces>\cron-match\cron.js, dependency free, evaluated in UTC.

- Validates types first: non-string expression or invalid Date throws TypeError.
- Splits on whitespace (trimmed), requires exactly 5 fields, and parses every field before matching, so malformed expressions throw SyntaxError regardless of the date.
- Supports *, N, A-B, */S and A-B/S with comma lists. Range checks per field (dow 0-6, 7 rejected). Rejects N/S, reversed ranges, step 0, empty or malformed items.
- Minute, hour and month must match. Day uses OR when neither dom nor dow starts with "*", otherwise AND.
