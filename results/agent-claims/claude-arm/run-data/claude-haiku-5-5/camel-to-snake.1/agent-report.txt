Implemented camelToSnake in <workspaces>\camel-to-snake\snake.js (dependency free, no other files touched).

Approach: iterate characters; for each ASCII capital A-Z, insert "_" if the previous char is a-z or 0-9, or if the previous char is A-Z and the next char is a-z (last capital of an acronym run starts a word). Capitals are lowercased by hand, so only ASCII letters change. Underscores are never doubled since "_" is not a word-start trigger. Non-string input throws TypeError; empty string returns "".
