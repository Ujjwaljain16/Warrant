Behavior:
- Throws TypeError immediately if fn is not a function, or if keyFn is given and is not a function.
- Key is keyFn(...args) when keyFn is given, otherwise args[0]. Stored in a Map, so keys follow Map semantics.
- The cache holds the promise for each key. A call with a key that is pending or fulfilled returns that same promise and does not call fn again.
- A rejection (or a synchronous throw from fn) is removed from the cache, so the next call with that key calls fn again. Waiting callers still see the rejection.
- fn receives all arguments of the call that triggered it.
- The returned function always returns a promise. If keyFn throws, the error is returned as a rejected promise.
